# Warped Pixel Dungeon

**Warped Pixel Dungeon** is an open-source roguelike dungeon crawler built on top of [Shattered Pixel Dungeon](https://shatteredpixel.com/shatteredpd/) by [Evan Debenham](https://github.com/00-Evan), which itself is based on [Pixel Dungeon](https://github.com/00-Evan/pixel-dungeon-gradle) by [Watabou](https://watabou.itch.io/).

It incorporates ideas and code from several other PD mods including [Sprouted PD](https://github.com/dachhack/SproutedPixelDungeon), Overgrown PD, and others — blending them into a unique experience with new mechanics, items, and systems.

## What's Different?

- A town and an open overworld on the surface, above the dungeon
- Day/night cycle, seasons, moon phases and a weather system (rain, snow, wind, storms)
- Temperature: hypothermia and heatstroke, with torches, fire and shelter to counter them
- Living plants that grow from seeds, passive plant growth and grass regrowth
- Per-class skill trees with active skills on a quick-use HUD panel
- Expanded inventory (43 usable backpack slots) plus food pouch, ankh chain and key ring bags
- Guns, bows, new potions, items, enchantments and mobs ported from multiple PD mods
- Local co-op over LAN, and online co-op through a room code
- And more weird stuff in the works...
